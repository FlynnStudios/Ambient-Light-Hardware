# Ambient Light / Smart Wake-Up Light

A Bluetooth-controlled smart wake-up light with dual-channel warm/cool LED dimming, developed through multiple PCB revisions, hardware debugging, and small-batch production.

## Project Highlights

- 5–6 PCB design and hardware revision cycles
- Dual-channel warm/cool LED PWM dimming
- Tuya Bluetooth control
- Hands-on SMT assembly, rework, and hardware debugging
- Iterative improvements addressing board noise, thermal concentration, and enclosure-related RF attenuation
- 30+ units built and tested
- Silver Award, Jinan University Challenge Cup
